# Schedule Time

一个可安装到手机主屏的个人学期计划工具。桌面端是周视图 + 任务清单，手机端是当天时间线；支持任务快速捕获、自动排期、专注计时、每周目标与复盘、离线缓存和可选云同步。

## 使用

直接打开 `index.html`，或：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。手机与电脑在同一局域网时，也可以用电脑的局域网地址访问。

## 功能

- **学期路线图**：课程 / 固定节奏与具体任务分层显示。
- **手机当天视图**：查看当天安排、快速记任务、调整已有日程。
- **自动排期**：新任务从明天开始，不回填今天或过去；今天已有安排保留。
- **依赖顺序**：带 `series` / `seq` 的任务（例如 D1→D2→D3）按顺序逐日推进，后一项不会排到前一项之前。
- **目标与复盘**：周目标、完成记录、卡点与下一步。
- **离线与备份**：Service Worker 缓存；JSON 导入 / 导出。
- **私人云同步（可选）**：Supabase Auth + 行级权限；默认不连接、不上传。

## 私人云同步

1. 在 Supabase 创建个人项目（建议 Singapore）。
2. 在 SQL Editor 执行 `supabase/schema.sql`。
3. 在页面「同步」中填写 Project URL 和 **Publishable key**；创建 / 登录 Supabase 账户。
4. 不要使用 Secret / `service_role` key。它们不能出现在网页或仓库里。

## 定制

- 课程：页面「固定时段」中编辑，或修改 `COURSES`。
- 每周论文产出 / 课程节奏：修改 `ROUTINE`，或在「固定时段」中增删。
- 学期起点：修改 `SEM_START`。
- 初始示例任务：修改 `seed()`。

## 隐私

这是一个通用模板，不包含任何个人课程表、研究任务或密钥。你的任务保存在自己的浏览器 / Supabase 项目中。GitHub Pages 站点默认公开；不要把私人计划数据写进这个仓库。

## 说明

GitHub Pages 只托管静态文件，不会自动同步浏览器数据。跨设备同步需要 Supabase 或其他有账号与权限控制的后端。
